# THIS IS ME PROJECT — Z軸

アートシンキングの授業で制作したミクストメディア作品「Z軸」と、その作品を紹介するために制作したWebサイトです。

「THIS IS ME」をテーマに、これまで自分を形成してきた記憶・経験・嗜好・日用品などの断片を集め、一つの作品として再構成しました。

## About

「自己とは何か？」という問いから制作を始めました。

考えていく中で、自分自身は突然できあがったものではなく、これまでの経験や記憶、好きだったもの、日常で使っていたものなど、さまざまな断片の積み重ねによって形成されているのではないかと考えました。

そこで、現在は使わなくなったものや、過去に夢中になっていたもの、自分の生活や記憶に結びついているものを素材として集め、一つの作品にしています。

作品名の「Z軸」には、

* 時間を表す X軸
* 好きなものや価値観を表す Y軸
* 経験や感情によって生まれる「厚み」を表す Z軸

という意味を込めています。

また、自分たちが「Z世代」と呼ばれる世代であることにも重ねています。

## Artwork

### Concept

かつて自分の日常に存在していた物や記憶の断片を集めて構成した、ミクストメディア作品です。

キャンバスを人間そのものに見立て、

* 表面：他者から見える自分
* 裏面：他者からは見えない内面的な自分
* 側面：その二つをつなぐ厚み

として構成しています。

中学生の頃にモネの作品に強く影響を受けた経験から、キャンバスの背景には青や緑を中心とした色彩を使用しています。

### Main Elements

#### 青いキャンバス

モネの作品から受けた印象をベースに、青を中心として緑・黄色・赤など複数の色を重ねています。

複数の色が混ざり合う背景によって、さまざまな経験や価値観によって形成される自己を表現しています。

#### ラーメン丼

白いボウルを人間の「頭部」に見立てています。

中には毛糸やミニチュア、キーホルダーなど、自分の記憶や好きなものに関連するオブジェクトを配置しています。

#### 衣服

実際に着用していた服を使用し、身体部分として作品に取り入れています。

既製品ではなく、自分自身が日常で使用していたものを作品へ直接取り込むことで、より個人的な自己表現にしています。

#### ミニチュアラーメン

衣服の上に配置し、自分の身体を構成する要素の一つとして表現しています。

ラーメンは長年好きなものであり、自分自身を象徴するモチーフの一つです。

#### CD・CDケース

裏面には、過去によく聴いていたCDに関連する素材を使用しています。

CDを「記憶を保存するメディア」として捉え、表からは見えない自分の記憶や内面を表現する要素として配置しました。

## Website

このWebサイトは、制作した作品そのものだけでなく、

* 制作コンセプト
* 表面・裏面の意味
* 制作工程
* 使用した素材
* 作品写真

などをWeb上で体験できるようにすることを目的として制作しています。

単純な作品紹介ページではなく、作品の世界観をWebデザインやインタラクションにも反映しています。

### Design

#### モネをイメージした背景

Canvas APIを使用し、青を中心とした複数の色や光、粒子を描画しています。

作品制作の原点となったモネの印象と、複数の記憶や経験が混ざり合う自己のイメージを表現しています。

#### 3D Artwork

Three.jsを使用し、作品の表面・裏面・側面の画像を立体的に表示しています。

マウス操作によって作品を回転させ、平面的な写真だけでは分かりにくい作品の構造を確認できるようにしています。

#### Responsive Design

PCだけでなく、スマートフォンやタブレットからも閲覧できるようレスポンシブ対応を行っています。

## Development

Webサイト制作では、HTML・CSS・JavaScriptの骨組みとなる部分を生成AIにコーディングしてもらい、そのコードをベースとして制作を進めました。

その後、自分で以下のような調整・実装を行っています。

* レイアウト調整
* 配色や余白の調整
* レスポンシブ対応
* 画像やコンテンツの配置調整
* Three.jsによる作品表示の調整
* Canvas背景の調整
* ナビゲーションや各セクションの見た目の調整
* HTML / CSS / JavaScriptのデバッグ
* ファイル構成やパスの整理

生成AIを完成コードとしてそのまま使用するのではなく、サイトの構成を考えるためのベースとして活用し、作品の世界観や見せ方に合わせて調整・修正を行っています。

使用した主な制作環境・技術：

* HTML
* CSS
* JavaScript
* Three.js
* Canvas API
* Git / GitHub
* GitHub Copilot
* 生成AIによるコーディング補助
